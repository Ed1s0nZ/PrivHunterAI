# 工作台体验深化

## Workflow Gate Report
- User request: 功能和页面过简，深化使用体验、交互与场景功能。
- Phase: P10；已有功能但缺少任务导向信息和操作闭环。
- Required/found artifacts: 当前页面、实际 API、用户截图、已有重构契约。
- Implementation allowed: yes，依据实际数据逐步扩展，不用虚构演示指标。
- Execution scope: 先完成工作台总览、配置就绪提示与可点击的复核队列；后续完善结果处理、配置体验与成员操作。
- Acceptance: 统计口径明确；空数据可指引下一步；只读角色看不到配置操作；指标跳转筛选；图表可访问；异常可重试。
- Risks: 不把模型推断当作确证，不自动发起额外攻击性测试；敏感字段不进入新的汇总接口。

## 页面职责和待扩展方向

| 页面 | 核心任务 | 体验与功能 |
| --- | --- | --- |
| 概览 | 判断优先处理什么、系统能否工作 | 真正的待复核/已确认/已解决指标、七日趋势、结果分布、目标热点、最近检测、就绪检查和快捷入口 |
| 结果 | 快速定位证据并形成结论 | 从概览带入筛选、复核状态、请求/响应对比；后续增加日期与方法筛选、批量复核、详情标签页与键盘操作 |
| 扫描控制 | 安全且清楚地启动采集 | 目标范围和账号 B 配置、暂停、队列状态；后续拆分范围/身份/过滤步骤，操作前显示缺失条件、配置保存反馈与帮助 |
| 系统设置 | 维护模型与运行配置 | 密钥保密、保留/清除区别、模型配置；后续增加连接测试（不发送流量）、重试状态与配置草稿提示 |
| 用户管理 | 最小权限协作 | 创建/停用账号；后续完善角色调整确认、自身操作提示、最后管理员保护说明 |
| 审计 | 知道谁在什么时间改变了什么 | 记录时间、操作者、对象；后续增加可读操作文案与搜索 |

以上方向以完整用户流程优先排序。历史记录为空时不填充假数据；不凭空展示成本、令牌数或模型准确率。此轮先完成可用概览和跨页定位，其他深化需要继续实施与独立验收。

## 此轮已实施与验证

- 概览：真实待复核/已确认/失败口径、北京时间七日趋势、判定分布、完成复核比例、目标热点、最近记录、采集就绪状态；点击带入结果筛选；后台页面可见时每 30 秒刷新。
- 结果：请求/响应标签切换、最多 500 个 JSON 差异字段、复制脱敏证据、当前页多选与事务批量复核、清除筛选、Esc 关闭。
- 成员：用户名检索、角色调整确认、停用确认、禁止在界面停用自身；后端最后管理员保护继续有效。
- 验证：TypeScript/Vite 构建、Go 测试与竞态检查通过；2 项 Playwright 流程通过，含新增指标跳转筛选与批量复核。服务已更新到 8222。

## 后续功能建议（尚未实施）

1. 项目/目标工作区：每个项目独立范围、身份和检测记录；切换项目不会串用凭证。
2. 身份配置管理：命名账号、角色标签、凭证替换与到期提醒，不返回明文。
3. 扫描任务历史：采集开始/结束、配置快照、失败原因、重试审批与关联结果。
4. 报告中心：基于人工确认结果生成可分享的脱敏报告，保留导出范围和版本。
5. 模型运行记录：实际记录耗时、token 与失败分类，再展示成本与效果；不推算假指标。

项目隔离和多身份会改变数据模型与扫描归属，需要单独的数据迁移及权限验收。
